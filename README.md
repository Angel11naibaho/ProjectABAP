# SAP ABAP – Purchase Order Display

## Project Overview
This is a beginner-level SAP ABAP self-learning project focused on retrieving and displaying Purchase Order (PO) header information from the standard SAP EKKO table.

## Project Objective
The objective of this project is to practice basic ABAP programming and understand how to retrieve purchasing document information.

## SAP Table Used

**EKKO – Purchasing Document Header**

| Field | Description |
|---|---|
| EBELN | Purchase Order Number |
| BUKRS | Company Code |
| LIFNR | Vendor Account Number |
| BEDAT | Document Date |
| EKORG | Purchasing Organization |

## Main Features

- Search Purchase Order by document number.
- Retrieve PO header information.
- Display purchasing document details.
- Validate whether the requested PO exists.

## ABAP Concepts Applied

- PARAMETERS
- DATA Declaration
- SELECT SINGLE
- Open SQL
- WHERE Clause
- SY-SUBRC
- IF-ELSE
- WRITE Statement
  
## Learning Outcomes
Through this project, I aim to improve my understanding of SAP MM purchasing document structures and practice basic ABAP programming.

## Disclaimer
This is an independent self-learning project. The source code has not yet been executed or tested in an SAP system due to the current lack of SAP system access.
